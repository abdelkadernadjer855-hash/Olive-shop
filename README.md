# نظام إدارة محل الزيتون والمشتقات

هذا المشروع عبارة عن تطبيق ويب بسيط ومحلي لإدارة مخزون محل الزيتون، تتبع السلع الداخلة، المبيعات، الكميات المتبقية، رأس المال والأرباح.

## كيفية الاستخدام والرفع على GitHub:
1. قم بفك ضغط ملف `olive-shop-app.zip`.
2. ستجد بداخله ملف `index.html`.
3. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
4. ارفع ملف `index.html` إلى المستودع.
5. اذهب إلى إعدادات المستودع (Settings) ثم (Pages) وفعل النشر من فرع `main` ليصبح لديك رابط مباشر لتطبيقك على الويب!
